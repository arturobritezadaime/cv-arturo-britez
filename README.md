## 📄 Sobre este repositorio

Este repositorio aloja mi **currículum vitae interactivo**, construido en HTML/CSS/JS puro (sin frameworks ni dependencias de build), pensado para verse igual de bien en pantalla que impreso en PDF.

🔗 **[Ver CV en línea →](https://arturobritezadaime.github.io/cv-arturo-britez/)**

## ✨ Características

- 🌐 **Bilingüe (ES/EN)** — toggle de idioma instantáneo, sin recargar la página.
- 📱 **100% responsive** — optimizado para mobile, tablet y desktop.
- 🖨️ **Exportación a PDF** — hoja de estilos `@media print` dedicada, con saltos de página controlados (`break-inside: avoid`) y elementos interactivos ocultos al imprimir.
- ♿ **Accesible** — landmarks semánticos, *skip link*, foco visible (`:focus-visible`), `aria-label`/`aria-pressed` en controles y soporte de `prefers-reduced-motion`.
- 🔍 **SEO técnico** — meta tags Open Graph, Twitter Card y datos estructurados [Schema.org `Person`](https://schema.org/Person) en JSON-LD para una correcta indexación en buscadores, LinkedIn y sistemas ATS.
- 🎬 **Microinteracciones sutiles** — animación de aparición al hacer scroll vía `IntersectionObserver`, sin dependencias externas.
